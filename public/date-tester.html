This page is temporary

Everything here is read-only — it never touches accounts, requests, or the database. It asks the real server (src/eligibility.js) what it would do, so a green result here means the live site behaves the same way.

Nothing on the main site links here — you reach it by typing the URL. To delete it entirely, remove public/date-tester.html, public/date-tester.js, src/routes/dateTester.js, and the two dateTester lines in server.js.

1. Pretend it's…

Pick any date and time, and the server will answer as if that were right now.

2. Check every closed day at once

For each day on the no-tutoring list, this asks the server to book a session on it (from a week earlier, so the day is inside the two-week sign-up window) and confirms the booking is refused. As a control, it also books a normal day in the same window and confirms that one is accepted — so a green run means the calendar is blocking the right days, not everything.
